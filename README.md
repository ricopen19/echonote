# Echonote

音声ファイルから構造化されたテキスト記録を生成するローカル完結型アプリケーション。

---

## Windows セットアップ（初回のみ）

### ステップ 1 — ファイルを入手する

**方法 A: ZIP ダウンロード（推奨・git 不要）**

1. このページ右上の「Code」→「Download ZIP」をクリック
2. ダウンロードした ZIP を右クリック →「すべて展開」
3. 展開先のフォルダ（例: `C:\echonote`）を覚えておく

**方法 B: git clone（更新を `git pull` で管理したい場合）**

```powershell
git clone https://github.com/ricopen19/echonote.git
cd echonote
```

---

### ステップ 2 — `setup.bat` をダブルクリック

フォルダ内の `setup.bat` をダブルクリックします。

「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら **「はい」** をクリックしてください。

画面の指示に従うと Python・ffmpeg・Ollama・AI モデルが自動でインストールされます。

> **「Installing Ollama...」で数分以上止まった場合**  
> Ollama のインストール完了と同時に Ollama のウィンドウが開きますが、セットアップスクリプトがそのプロセスを待ち続けてハングすることがあります。  
> Ollama のウィンドウが開いたら `setup.bat` の PowerShell ウィンドウで **Ctrl+C** を押して中断し、`setup.bat` をもう一度ダブルクリックしてください。2回目は Ollama のインストールをスキップして先に進みます。

完了後、**PC を再起動**してください。

### ステップ 3 — 以降は `start.bat` をダブルクリック

`start.bat` をダブルクリックするとブラウザが開きます。

## アンインストール

1. フォルダ内の `uninstall.bat` をダブルクリック
2. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
3. 画面の指示に従う

以下が自動で削除されます：

| 削除対象 | 内容 |
|---|---|
| `.venv` | Python 仮想環境（依存パッケージ一式） |
| Whisper モデルキャッシュ | 文字起こし用 AI モデル（数 GB） |
| Ollama モデル | 記録生成用 AI モデル（約 2.5 GB） |

セットアップ時にインストールしたツール（Python・FFmpeg・Ollama・Git）は個別に削除するか確認されます。**他のアプリで使用している場合は N を選んでください。**

最後に Echonote のフォルダ自体を手動で削除すれば完全にクリーンな状態に戻ります。

---

## アップデート（新しいバージョンが出たとき）

1. 新しい ZIP をダウンロードして同じ場所に上書き展開
2. **`start.bat` をダブルクリック**するだけで最新版が起動します

> `setup.bat` を再度実行する必要はありません。

## 使い方

1. 「📝 文字起こし」タブで音声ファイル（mp3, wav, m4a など）をアップロード
2. 「▶ 文字起こし開始」をクリック（**初回はモデルのダウンロードで数分かかります**）
3. 文字起こし結果が出たら「📄 記録生成」タブへ
4. テンプレートを選んで「▶ 記録を生成」
5. 「📥 Markdown をダウンロード」で保存

### 話者分離

- 「📝 文字起こし」タブで「話者分離を実行」にチェックを入れると、発言ごとに話者ラベルが付きます。既定の方式（resemblyzer）は HF トークン不要です
- 文字起こし済みのテキストがある場合は「📋 貼り付け転写」タブを使います。音声とテキストを渡すと、Whisper を使わずに話者だけを割り当てます（非力な PC 向け）

### 初回設定（設定タブ）

LLM のモデル名の既定値は、PC の性能（HW ティア）で自動的に決まります。

| 項目 | 値 |
|---|---|
| LLM エンドポイント URL | `http://localhost:11434/v1`（Ollama） |
| LLM モデル名（Light） | `qwen3:1.7b` |
| LLM モデル名（Standard） | `hf.co/LiquidAI/LFM2.5-1.2B-JP-202606-GGUF:Q4_K_M` |
| LLM モデル名（Performance） | `qwen3:14b-q4_K_M` |

## Mac セットアップ（開発者向け）

```bash
# mlx-whisper（Apple Silicon 最適化）と話者分離を含めてインストール
uv sync --extra mac --extra diarization

# LLM サーバーを起動（別ターミナル）
uvx --from mlx-lm mlx_lm.server --model <モデル名>

# Echonote を起動
uv run echonote
```

### 初回設定（設定タブ）

Mac の LLM エンドポイント URL の既定値は `http://localhost:8080/v1`（mlx-lm）です。Ollama を使う場合は `http://localhost:11434/v1` に変えてください。モデル名の既定値は Windows と同じく HW ティアで決まります。
